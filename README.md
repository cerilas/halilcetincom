# Halil Çetin Hair Transplant

Next.js 16 + Tailwind v4. Scroll animasyonlu klinik sitesi, JSON CMS ve admin paneli.

## Geliştirme

```bash
npm install
npm run dev
```

- Site: [http://localhost:3000](http://localhost:3000)
- Admin: [http://localhost:3000/admin](http://localhost:3000/admin)
- Varsayılan şifre: `halilcetin2026` (`.env.local`)

Plan: `PLAN.md`

Admin’den kaydedilen içerik `data/content.json` dosyasına yazılır. İletişim formları `data/inquiries.json` içinde birikir.
